# 模式分解模型文件夹

把训练好的模态分解模型文件复制到这个文件夹中，网页右下角“模型”助手会自动扫描并列出。

## 支持的文件格式

- `.pth` / `.pt`（PyTorch 权重，DualBranchFiberNet 结构，直接保存 `state_dict` 或
  `model_state_dict` 均可）
- `.ckpt`（PyTorch 检查点）

## 模型要求

- 采用双分支网络结构（权重分支 + 相对相位分支），对应
  `scripts/predict_worker.py` 中的 `DualBranchFiberNet`。
- 支持骨干：`efficientnet_b0`、`vgg16`、`resnet152`、`mobilenetv3_small/large`、
  `mobilenetv4_small/medium`、`unet`。程序会自动从权重键名推断骨干网络。
- 模型输入：近场灰度图 + 远场灰度图 + 零通道构成的 224×224 RGB 图像
  （ImageNet 归一化），与 `测试代码（预测参数）.py` 的数据管线一致。

## 模式标签（可选）

如需在网页中显示与数据集一致的模式名（如 `LP01e`、`LP11o`），可把数据集的
`labels.csv` 复制到与模型文件相同的文件夹中。未提供时会使用
`mode_01 … mode_NN` 通用名称。

## 使用提示

1. 复制模型文件后，点击右下角“模型”面板右上角的 ↻ 刷新。
2. 选择一个模型（面板会显示模式数与骨干网络）。
3. 先完成光斑仿真，再点击“模态预测（AI 模式分解）”。
4. 当前仿真启用的模式数必须与模型的模式数一致（例如 85 模式模型需要仿真正好
   检测出 85 个空间模式分量），否则预测接口会提示调整光纤参数。
