# 少模光纤单光斑仿真器

浏览器内运行的少模光纤（FMF）LP 模式仿真工具：输入光纤参数，自动求解支持的 LP 模式，设置各模式的幅度权重与相位，相干叠加出**近场与远场单张光斑**，并可调用训练好的卷积网络做**模态分解（AI 反演）**，给出权重、相对相位与误差分析。

物理流程与参考 MATLAB 实现（`compute_lpmodes` / `synthesize_mode_field` / `crop_nearfield_adaptive`）逐像素对齐，见[一致性验证](#与-matlab-的一致性验证)。

- **仿真部分开箱即用**：纯 TypeScript 实现，无需 Python、无需 GPU，`pnpm dev` 后即可使用。
- **预测部分可选**：需要自备 Python 环境与模型权重，未配置时界面自动降级，不影响仿真。

## 功能

| 模块 | 说明 |
|---|---|
| 模式求解 | 由 V = 2πa·NA/λ 与弱导近似特征方程求根，枚举全部支持的 LP 模式及简并 |
| 模态设置 | 逐模式开关、幅度权重 w、相位 φ（-π ~ π），支持随机生成与 L2 归一化 |
| 光斑仿真 | 复振幅相干叠加 E = Σ wᵢe^{jφᵢ}Eᵢ，同步输出近场与远场 224×224 强度图 |
| 显示设置 | 95% 能量自适应裁剪、留白系数、Gamma、内部计算网格、输出尺寸 |
| 光纤组合 | 保存自定义参数组合，保存时自动用 50 组随机光斑预校准统一裁剪比例 |
| 模态分解 | 加载 PyTorch 模型反演权重与相对相位，输出残差图、Pearson、SSIM 与三线表 |

## 快速开始

需要 Node.js ≥ 22.13 与 pnpm。

```bash
pnpm install
pnpm dev
```

浏览器打开 <http://127.0.0.1:3000>，即可使用完整仿真功能。

Windows 下有三个双击入口，按需要选一个：

| 入口 | 作用 |
|---|---|
| `启动网页.bat` | 只启动网页服务（:3000）。仿真可用，预测不可用 |
| `启动后端.bat` | 同时启动网页服务与预测旁路（:3099）。功能完整 |
| `前端.html` | 带等待页的启动器。先双击它，再启动后端；它会自动探测 :3000，连上后切入界面，不显示浏览器自己的错误页 |

`前端.html` 是纯静态页面，不依赖 Node。端口被占用时可以带参数改用其他端口：`前端.html?port=3001` 或 `前端.html?url=http://127.0.0.1:3001`。

> 仅执行 `pnpm dev` 时，**仿真可用、模型预测不可用**。预测需要额外的 Python 旁路服务，见下一节。

## 配置模态预测（可选）

预测链路由 `backend.mjs` 拉起：它同时启动网页服务（:3000）与预测旁路服务（:3099），后者通过 stdin/stdout 调用 `scripts/predict_worker.py` 完成模型扫描与推理。

### 1. 准备 Python 环境

需要包含 `torch`、`torchvision`、`timm`、`numpy`、`Pillow`、`scipy`：

```bash
conda create -n fmf python=3.10
conda activate fmf
pip install torch torchvision timm numpy pillow scipy
```

### 2. 放入模型权重

`models/` 已内置 6 个训练好的权重（模式数 `3` / `6` / `10` / `12` / `25` / `30`），
开箱即用。如需替换为自己训练的模型，把 `.pth` / `.pt` / `.ckpt` 放进该目录即可，
权重约 26 MB/个，体积较大，不建议提交到版本库。模型对输入通道的要求见
`models/README.md`：三通道（`in_chans=3`）与双通道（`in_chans=2`）权重都可以直接使用，
双通道权重会自动适配到推理端固定的三通道输入。

### 3. 让后端找到这个 Python

按以下优先级自动探测，**任选一种**即可：

1. 先 `conda activate fmf`，再启动后端（自动读取 `CONDA_PREFIX`）；
2. 设置环境变量 `LP_PREDICT_PYTHON` 指向解释器；
3. 启动时传参：`启动后端.bat "C:\path\to\envs\fmf\python.exe"`；
4. 兜底会尝试 PATH 中的 `python3` / `python` / `py`。

最省事的做法是在项目根目录新建 `.lp-python.txt`，首行写下解释器绝对路径；该文件已被 `.gitignore` 忽略，不会进入版本库，之后每次双击 `启动后端.bat` 即可自动使用。

### 4. 启动并选择模型

```bash
pnpm backend      # 等价于 node backend.mjs
```

右下角「模型」助手会自动扫描并显示每个模型的模式数与骨干网络。仿真完成后点击「模态预测」即可得到反演结果。

> **模式数必须匹配**：模型只接受与训练集相同数量的空间模式分量。`fiber-profiles/` 内置了与
> 6 个权重一一对应的组合，在左侧「查看已保存组合」中选中同名组合（如「12 模式 (a=5, NA=0.13, zone=30)」），
> 光纤参数、`zoneSize` 与固定裁剪比例都会自动对齐。这些组合的参数直接取自训练数据集的
> `dataset_metadata.mat`，在该参数下仿真结果与训练集 PNG 逐像素一致（Pearson ≥ 0.9999），
> 因此**不要手工微调**，否则输入分布会偏离训练分布。

若预测按钮提示 Python 环境不可用，请检查解释器路径与依赖是否齐全；界面会直接显示后端返回的具体原因。

## 使用流程

```
设置光纤参数 → 检测 LP 模式 → 调整 w、φ → 归一化 → 开始仿真 → （可选）模态预测
```

1. **光纤参数**：纤芯半径 a、数值孔径 NA、工作波长 λ、计算区域。长度单位统一为 μm，波长输入框以 nm 显示，V 数实时更新。
2. **检测模式**：调用 `POST /api/modes` 求解特征方程，返回模式列表。修改光纤参数后需重新检测。
3. **模态参数**：开关决定是否参与合成；随机按钮按 w ∈ [0.45, 1.00]、φ ∈ [-π, π] 生成，与数据集脚本一致。
4. **归一化**：按 L2 范数缩放启用模式，使 Σwᵢ² = 1。修改任何模式参数后都需要重新归一化。
5. **开始仿真**：`POST /api/simulate` 返回近场与远场强度图，可分别下载 PNG。

### 保存光纤组合

在「自定义光纤组合」中填写名称并点击「校准并保存当前组合」。后端会生成 50 组全模式随机光斑，按 MATLAB 脚本的 P95 × 1.10 规则算出统一固定裁剪半宽比例，连同光纤参数、模式数量、模式标签与显示参数一并写入 `fiber-profiles/`。之后再预测时使用该固定裁剪，可保证输入分布与训练集一致。

## 接口

| 接口 | 说明 |
|---|---|
| `POST /api/modes` | 入参 fiber（coreRadius、na、wavelength、zoneSize、maxL、maxM），返回 V 数与模式列表 |
| `POST /api/simulate` | 入参 fiber、modes、display，返回近远场 RGBA Base64、总功率与裁剪信息 |
| `GET /api/models` | 返回模型列表、Python 环境可用性与模型目录 |
| `POST /api/predict` | 入参 fiber、modes、display、model，返回系数、残差图、相位图与误差表 |

`POST /api/predict` 会先按显示设置生成 224×224 灰度近远场作为网络输入，再计算：

- 近场 / 远场 Pearson 相似系数与 SSIM；
- 真值、重构与残差图，以及带强度掩码的相位图；
- 权重 MSE、相位 MAE，以及逐模态的绝对 / 相对权重误差与相位误差。

## 物理模型

- 弱导近似下的标量 LP 模式。
- 纤芯内径向场：Jₗ(u·r/a)；包层内：Jₗ(u)Kₗ(w·r/a)/Kₗ(w)。
- 特征关系：u² + w² = V²；偶模角向项 cos(lφ)，奇模为 sin(lφ)。
- 合成光场：E = Σ wᵢ·exp(jφᵢ)·Eᵢ；近场强度 I = |E|²。
- 远场：对近场复振幅加 Hann 窗、4 倍零填充，再执行 `fftshift(fft2(ifftshift(·)))`。
- 显示使用 Gamma 0.7 与 Jet 伪彩色；模型输入与 Pearson / SSIM 始终使用灰度强度数组，配色不影响数值结果。

## 与 MATLAB 的一致性验证

同一组确定性模态参数下（默认 `a = 10 μm`、`NA = 0.179`、`λ = 632.8 nm`）：

| 检查项 | 结果 |
|---|---:|
| V 数 | 17.7732327747 |
| 模式数与顺序 | 70 个空间模式，标签与顺序一致 |
| 95% 能量半径 | 47.5078940808788 px（两端一致） |
| 裁剪半宽 / 比例 | 54 px / 0.18（两端一致） |
| 裁剪后 108×108 灰度图 | 逐像素 100% 一致 |
| 缩放到 224×224 | 相关系数 0.999980，MAE 0.154 灰度级，最大误差 ≤ 1 级 |

最后不超过 1 个灰度级的差异来自 MATLAB `imresize` 与 JavaScript 对 uint8 双线性插值的取整方式不同，不影响光场结构或能量裁剪。

## 常见问题

- **改了参数但结果没变**：修改光纤参数后需重新「检测支持的 LP 模式」；修改模式参数后需重新归一化并重新仿真。
- **提示「请先完成权重归一化」**：点击第 3 步的归一化按钮。
- **预测按钮不可用**：确认通过 `pnpm backend`（或 `启动后端.bat`）启动，而非只有 `pnpm dev`；并确认模型模式数与当前仿真一致。
- **端口被占用**：`scripts/cleanup-backend.ps1` 会按 PID + 进程创建时间校验后释放 3000 / 3099 端口，`backend.mjs` 启动时会自动调用。
- **参数较大时变慢**：支持模式数增多会让场合成耗时线性上升，可先降低内部计算网格（600 → 320）验证效果。

## 说明

本项目只做单张光斑仿真，不包含批量数据集生成、CSV 标签导出或训练流程。若需要与训练集完全同分布的数据，请使用配套的 MATLAB 生成脚本。
