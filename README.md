# 少模光纤单光斑仿真器

这是一个参考 generate_dataset_matlab.m 物理流程实现的前后端分离网页。它根据阶跃型光纤参数自动检测受支持的 LP 模式，设置各模式的幅度权重 w 与相位 φ，归一化后同步生成少模近场与远场光斑。

## 功能

1. 设置纤芯半径、数值孔径、工作波长和计算区域。
2. 后端根据 V = 2πa·NA/λ 求解支持的 LP 模式。
3. 启用或关闭模式，逐模式调整幅度权重 w 与相位 φ。
4. “随机参数”按钮生成 w ∈ [0.45, 1.00]、φ ∈ [-π, π]。
5. 对启用模式执行 L2 归一化，使 Σwᵢ² = 1。
6. 后端相干叠加模式，同步返回近场与远场 224 × 224 强度图。
7. 分别下载近场或远场光斑为 PNG。
8. 在独立“仿真设置”界面控制 95% 能量自适应裁剪、留白、Gamma、计算网格和输出尺寸。

## 操作流程

    设置光纤参数 → 检测 LP 模式 → 调整/随机 w、φ → 归一化 → 开始仿真

修改光纤参数后需要重新检测模式。修改任意模式的启用状态、权重或相位后需要重新归一化。

## 前后端接口

### POST /api/modes

请求体包含 fiber 对象：coreRadius、na、wavelength、zoneSize、maxL、maxM。长度单位统一使用 μm。接口返回 V 数及每个模式的 l、m、奇偶简并、u、w 和截止值。

### POST /api/simulate

请求体包含光纤参数、设置后的模式数组及 display 设置。后端返回近场、远场 RGBA 光斑数据的 Base64 编码、总功率及各自裁剪信息；前端将两张图绘制到 Canvas。

## 物理模型

- 弱导近似下的标量 LP 模式。
- 纤芯内径向场：Jₗ(u·r/a)。
- 包层内径向场：Jₗ(u)Kₗ(w·r/a)/Kₗ(w)。
- 特征关系：u² + w² = V²。
- 偶模角向项：cos(lφ)；奇模角向项：sin(lφ)。
- 合成光场：E = Σ wᵢ exp(jφᵢ) Eᵢ。
- 近场强度：I = |E|²，归一化后使用 Gamma = 0.7。
- 远场强度：对近场复振幅施加 Hann 窗、4 倍零填充，再执行 fftshift(fft2(ifftshift(·)))；流程与参考 MATLAB 脚本一致。

该模型与参考 MATLAB 脚本中的 prime_mode_cal、compute_lpmodes 和 synthesize_mode_field 计算思路一致。

## MATLAB 一致性验证

项目保留 validation/matlab_reference.m，可使用 MATLAB R2024a 对同一组确定性模态参数生成参考图。

当前默认参数验证结果：

- V 数：17.7732327747。
- MATLAB 与网页后端均检测到 70 个空间模式，标签和顺序一致。
- 强度质心一致：MATLAB 的 (318, 302) 为 1 基坐标，对应网页的 (317, 301) 0 基坐标。
- 95% 能量半径：47.5078940808788 像素，两端一致。
- 裁剪半宽：54 像素，两端一致。
- 裁剪比例：0.18，两端一致。
- 裁剪后、缩放前的 108 × 108 灰度图逐像素 100% 一致。
- 缩放到 224 × 224 后相关系数为 0.999979977371，平均绝对误差为 0.154436 灰度级，全部像素误差不超过 1 灰度级。

最后不超过 1 灰度级的差异来自 MATLAB imresize 与 JavaScript 对 uint8 双线性插值的整数舍入实现差异，不影响物理光场、能量裁剪或光斑结构。

## 本地运行

需要 Node.js 22.13 或更高版本，以及 pnpm。

### 推荐启动方式：后端脚本 + 前端 HTML

第一步，启动后端。可双击：

    启动后端.bat

也可以在项目目录执行：

    node 后端.mjs

当窗口显示后端地址 http://localhost:3000 后，保持窗口打开。

第二步，双击：

    前端.html

HTML 会连接本地后端并载入完整仿真界面。关闭后端窗口或按 Ctrl+C 即可停止服务。

此启动方式完全使用 JavaScript/Node.js，没有移植到 Python。

### 兼容启动方式（Windows）

双击项目根目录中的“启动网页.bat”。脚本会检查 Node.js 与 pnpm；首次运行时自动安装依赖，随后启动本地网页。

启动成功后，在浏览器访问：

    http://127.0.0.1:3000

保持命令窗口打开。关闭窗口或按 Ctrl+C 即可停止网页服务。

### 开发命令

在项目目录打开 PowerShell：

    pnpm install
    pnpm dev

终端显示 Local 地址后，用浏览器打开该地址。默认通常为：

    http://localhost:3000

生产构建：

    pnpm build
    pnpm start

## 使用方法

### 第 1 步：设置光纤参数

填写纤芯半径 a、数值孔径 NA、工作波长 λ 和计算区域。网页中的长度统一以 μm 计算，波长输入框以 nm 显示。页面会即时显示 V 数。

点击“检测支持的 LP 模式”。前端会调用 POST /api/modes，后端根据当前物理参数求解特征方程并返回 LP 模式列表。

### 第 2 步：调整模态参数

- 使用模式左侧开关决定该模式是否参与合成。
- 拖动“幅度权重 w”滑块或直接输入数值。
- 拖动“相位 φ”滑块或直接输入弧度，范围为 -π 到 π。
- 点击“随机参数”，为所有已启用模式生成随机权重和随机相位。

随机按钮采用与 MATLAB 数据集脚本相同的参数范围：

- 原始权重：0.45 到 1.00。
- 相位：-π 到 π。

### 第 3 步：归一化

点击“归一化全部启用模式”。网页按 L2 范数处理启用模式：

    wᵢ ← wᵢ / sqrt(Σwᵢ²)

完成后应显示 Σwᵢ² = 1.000000。每次修改模式开关、权重或相位后，都需要重新执行归一化。

### 第 4 步：仿真单张光斑

点击“开始仿真”。前端把光纤参数和模态参数发送给 POST /api/simulate；后端计算各 LP 模式、执行复振幅相干叠加，并同步返回近场与远场两张 224 × 224 强度图。

仿真完成后可分别点击“下载近场 PNG”和“下载远场 PNG”保存结果。近远场图像内部不叠加坐标、比例尺或其他文字。

## 仿真设置界面

点击页面右上角“仿真设置”打开专门设置界面。

### 自适应能量裁剪

默认启用，与 MATLAB 的 crop_nearfield_adaptive 流程对应：

1. 分别计算完整近场、远场强度和强度加权质心。
2. 从质心向外累计能量。
3. 找到覆盖 95% 总能量的半径。
4. 将半径乘以 1.12 留白系数，得到正方形裁剪区域。
5. 将近远场裁剪结果分别重采样到设置的输出尺寸。

可设置：

- 自动裁剪：开启或关闭。
- 能量覆盖率：50% 到 99.9%，默认 95%。
- 裁剪留白系数：1.00 到 2.00，默认 1.12。
- Gamma：0.10 到 2.00，默认 0.70。
- 内部计算网格：224、320 或 600。默认 600，与参考 MATLAB 脚本的 cfg.sim.N 一致。
- 输出图像尺寸：128、224、256 或 320。

点击“恢复 MATLAB 默认设置”可恢复 95%、1.12、Gamma 0.70、600 计算网格和 224 输出尺寸。修改设置后需要重新点击“开始仿真”。

### 常见状态提示

- “光纤参数已改变”：重新点击“检测支持的 LP 模式”。
- “请先完成权重归一化”：点击第 3 步的归一化按钮。
- “至少启用一个模式”：打开至少一个模式，并保证其权重不为 0。
- 参数较大、支持模式较多时，后端计算时间会相应增加。

## 与数据集脚本的区别

本网页只进行单张光斑仿真，不包含批量样本、校准采样、统一裁剪、CSV 标签或近远场数据集生成。流程固定为“光纤参数 → 模态参数 → 归一化 → 单张光斑”。
